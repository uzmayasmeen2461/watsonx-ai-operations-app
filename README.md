AI-Powered Operations Monitoring System

This application integrates IBM watsonx.ai (Granite 3-8B Instruct) to enable natural language querying of operational data.

Features

AI-based filter extraction

Redux-managed state

React Query data fetching

Node.js AI gateway

Deterministic fallback logic

MUI enterprise UI

Model Used

IBM watsonx.ai
Model: ibm/granite-3-8b-instruct

Deployment

Frontend and backend are unified into a single Node.js service.

Environment variables required:

WATSONX_API_KEY

WATSONX_PROJECT_ID

WATSONX_URL
